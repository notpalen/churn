# Example: CSV Format Output

**Command**: `/churn "product feature ideas for Q2" 15 features --format csv`

**Context**: Need structured data for spreadsheet analysis, prioritization matrix, or stakeholder review.

**Output**:

```csv
id,text,type
1,Real-time collaboration on documents,features
2,Dark mode for entire application,features
3,Export reports to PDF format,features
4,Two-factor authentication support,features
5,Bulk user import via CSV,features
6,Advanced search with filters,features
7,Custom branding for workspaces,features
8,Webhook integrations for events,features
9,Role-based access control granular,features
10,Activity audit log viewer,features
11,Mobile app for iOS/Android,features
12,Email notification preferences,features
13,API rate limiting controls,features
14,Scheduled automated backups,features
15,Multi-language interface support,features
```

**Use case**: Import into Google Sheets, Excel, Airtable, or Notion database for:
- Prioritization scoring (add "priority" column)
- Effort estimation (add "estimate" column)
- Team voting (add columns per stakeholder)
- Roadmap planning (add "quarter" column)

**Outcome**: Structured data ready for collaborative prioritization and planning workflows.
